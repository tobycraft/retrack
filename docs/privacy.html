Privacy Policy — Minimize My Changes

Last updated: 2026-08-23

Minimize My Changes is a Word Add-in that scans a document's existing tracked changes, computes a word-level diff between each delete+insert pair's before/after text, and rewrites the result back into the document using Word's tracked-changes markup.

Data collection

This add-in does not collect, store, or transmit any data to us or to any third party. It has no backend server, no analytics, and no telemetry.

How your content is used

The add-in reads tracked-changes text from the document using the Office.js API (getTrackedChanges()) strictly to compute the diff, and writes the result back into the same document via native insertText()/delete() calls. It also briefly inserts and immediately removes one throwaway character at the start of the document to read the author name Word's tracked changes stamp automatically — this never leaves any trace in the document and nothing is saved or transmitted. There is no task pane and no field to type into; the add-in runs entirely from a ribbon button click. All processing happens locally, inside your instance of Word. Nothing is logged, cached remotely, or retained after the add-in finishes running. If something goes wrong, a small popup describing the error appears; it displays only text already generated locally and never loads any external resource.

Third parties

The only external resource this add-in loads is Microsoft's own office.js library, required by Microsoft for all Office Add-ins. No other third-party service, script, or tracker is used.

Hosting

The add-in's static files (this page, the hidden page that runs when the ribbon button is clicked, the error-popup page, and its icons) are served over HTTPS by GitHub Pages. GitHub's standard web server logs (e.g. IP address, requested file) may apply to those page loads per GitHub's own privacy statement; this add-in does not add any collection of its own on top of that.
