Privacy Policy — Paste Minimal Changes

Last updated: 2026-08-22

Paste Minimal Changes is a Word Add-in that computes a word-level diff between your current selection and your clipboard, then writes the result back into the document using Word's tracked-changes markup.

Data collection

This add-in does not collect, store, or transmit any data. It has no backend server, no analytics, and no telemetry.

How your content is used

The add-in reads the text of your current selection and your clipboard contents using the Office.js APIs (getSelection(), getOoxml()) strictly to compute the diff and to write the result back into the same document via insertOoxml(). All of this processing happens locally in the task pane, inside your instance of Word. Nothing is sent anywhere, logged, cached, or retained after you close the task pane or the document.

Third parties

The only external resource this add-in loads is Microsoft's own office.js library, required by Microsoft for all Office Add-ins. No other third-party service, script, or tracker is used.

Hosting

The add-in's static files (this page, the task pane, and its icons) are served over HTTPS by GitHub Pages. GitHub's standard web server logs (e.g. IP address, requested file) may apply to those page loads per GitHub's own privacy statement; this add-in does not add any collection of its own on top of that.
